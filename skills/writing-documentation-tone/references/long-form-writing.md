# Long-form writing

Use this guide for documents, guides, training resources, and professional summaries.

## Organization

- Use short, functional headings that tell readers what each section contains.
- Start with an overview when readers need orientation, group related details beneath it, and finish with next steps when the document points forward.
- Keep one main idea per paragraph and state it early.
- Use the same technical term consistently. Do not alternate between creative synonyms.
- Use numbered lists for procedures with concrete actions and exact values. Do not force a sequence when order does not matter.
- Use nested bullets to show how concepts, components, categories, or supporting details relate.
- Use tables only for genuinely tabular records such as dates, statuses, owners, or outcomes.

## Training and reference material

- Put important source links near the beginning and label them descriptively.
- Explain an unfamiliar term with a brief definition or parenthetical clarification close to its first use.
- Format commands, paths, configuration keys, and literal UI labels distinctly so readers can scan for them.
- Include practical rationale or impact, not just instructions. Prefer concrete contrasts such as measured time saved, fewer steps, or a clearly stated benefit.

## Professional summaries

- Group accomplishments by capability or area of work.
- Start each main bullet with the contribution or result, then add supporting detail in nested bullets.
- Separate completed work, work in progress, and what comes next.

Keep headings functional and easy to scan. A small conversational heading or brief celebratory aside is welcome when it suits the audience.
