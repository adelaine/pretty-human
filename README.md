# Pretty Human

Human guidelines for agents.

Pretty Human is a collection of skills that help agents communicate with clarity, warmth, and practical judgment. The guidance focuses on how agents write and respond: using natural language, respecting context, and preserving the writer's intent.

## Skills

| Skill | Purpose |
| --- | --- |
| [writing-documentation-tone](skills/writing-documentation-tone/SKILL.md) | Write clear, courteous messages and documentation with natural phrasing and precise technical language. |

## Using the collection

Open the relevant skill's `SKILL.md` for its scope and instructions. Follow its links to supporting guides in `references/` as needed. Each skill folder contains its own guidance and supporting files; keep that structure intact when copying it into an agent's skill location.
